# オフホワイトハッカー研究所

**白です。知らんけど。**

白から黒までのグラデーションで、あなたのハッカーカラーを厳正に決めつけるジョーク診断メーカー。
科学的根拠は 0。判定への自信は 120〜300%。最終承認者は自分と鳩です。

HTML ファイルを 1 枚開くだけで遊べます。

## 遊び方

このリポジトリをダウンロードし、`index.html` をブラウザーで開いてください。
ビルド、依存パッケージ、アカウント登録は不要。オフラインでも動きます。

ローカルサーバーで開きたい場合は、リポジトリのディレクトリで実行します。

```sh
python3 -m http.server 8000
```

ブラウザーで <http://localhost:8000> を開きます。

## できること

| 機能 | 研究内容 |
| --- | --- |
| 6 問で診断 | 白米、バナナ、冷蔵庫、靴下、エビ、鳩からあなたを決めつけます。 |
| 鳩に任せる | 未回答の質問を鳩が埋めます。あなたが答えた分はそのまま。 |
| 名前で生成 | 同じ名前には同じ偏見。日替わりモードは日本時間の日付で変わります。 |
| 色を調合 | 濃さを 0.1% 刻みで調整。本人の強い希望を反映できます。 |
| 64 色の図鑑 | 白っぽい 28 色、揉めてる 20 色、もう黒い 16 色。名前や言い訳で検索できます。 |
| 白だと言い張る | 測定された色はそのままに、本人の主張だけが強くなります。 |
| 法務を呼ぶ | 法務の不在に、さまざまなバリエーションがあります。 |
| 自称をコピー | 結果と主張をテキストでコピーできます。 |
| 証明書を発行 | 結果を PNG 画像で保存。この証明書に効力はありません。勢いはあります。 |
| HTML を保存 | アプリを単一ファイルで持ち帰れます。 |

- オフホワイト → オフオフホワイト → オフホワイト改
- エビ寄りグレー
- 鳩監修グレー
- ダークモードホワイト
- 黒（白の個人差）
- ブラック（白）

全員、白を主張しています。

## 中身

`index.html` に HTML、CSS、JavaScript、SVG をまとめています。
外部ライブラリー、外部画像、外部フォント、バックエンドは使っていません。
入力した名前や回答はブラウザー内で処理します。

色や言い訳を増やすなら `COLORS`、質問を変えるなら `QUESTIONS` を編集してください。
グラデーションの基準色は `COLOR_ANCHORS`、法務の行方は `LEGAL_RESPONSES` にあります。

これはジョークです。実際の技術力や倫理観は測定していません。
エビからわかることには限界があります。
